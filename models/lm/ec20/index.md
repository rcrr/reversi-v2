# models/lm/ec20/ — the model registry (the ec20 level)

Format (rigid, R-360): a two-column table, one row per model. The ID is the model's NNNN folder (4 digits,
sequential, never reused); the config cell is a relative markdown link to the model's config file. The model's
name and description live in the config file itself (the schema-required fields) — this index never duplicates
them.
